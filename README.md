# Circinus Overlay

Resource pack overlay for Conquest Reforged, made for the **Circinus** project on the [Wildeprojekt](https://wildeprojekt.org/) Minecraft server (`/warp Circinus`). It turns a few unused Conquest block families into large-scale painted metal (green, white, light blue and dark blue), including weathered and rusty variants. The textures tile seamlessly across 32×32 blocks and come with SEUS-compatible PBR maps.

Load it above ACRP.

## Blocks

| ID | Name |
|---|---|
| `conquest:mossy_sandstone` | Green Metal Plating |
| `conquest:large_inscribed_sandstone_block` | White Metal |
| `conquest:smooth_large_inscribed_sandstone_block` | Light Blue Metal |
| `conquest:irregular_sandstone_tiles` | Dark Blue Metal |
| `conquest:brown_sandstone_cobble` | Weathered Light Blue Metal |
| `conquest:mossy_lime_mortar_red_clay_brick` | Weathered Dark Blue Metal |
| `conquest:smooth_large_sandstone_block` | Rusty Light Blue Metal |
| `conquest:large_sandstone_block` | Rusty Dark Blue Metal |
