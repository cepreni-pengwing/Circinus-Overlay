# Circinus Overlay

Resource pack overlay for Conquest Reforged, made for the **Circinus** project on the [Wildeprojekt](https://wildeprojekt.org/) Minecraft server (`/warp Circinus`). It turns a few unused Conquest block families into large-scale painted metal (green, white, light blue and dark blue), including weathered and rusty variants. The textures tile seamlessly across 16×16 blocks and come with SEUS-compatible PBR maps.

Load it above ACRP.

## Lettering

Eurostile Extended Bold letters in Dark Blue Metal, placed in front of a facade (they snap to vertical slabs). Cycle the character with right-click (mallet); 2×2 identical letters merge into one large letter.

| ID | Characters | Toggle |
|---|---|---|
| `conquest:large_cobblestone_roman_oven` | A–H / I–P | right-click (toggle), shift + right-click (position 1 / 2) |
| `conquest:wooden_bowls` | Q–Z | right-click |
| `conquest:dark_wooden_bowls` | 0–9 | right-click |
